# Self-hosted fonts

Variable WOFF2 latin / latin-ext subsets of:

- [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) (SIL Open Font License)
- [Source Sans 3](https://fonts.google.com/specimen/Source+Sans+3) (SIL Open Font License)
- [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) (SIL Open Font License)

Licence texts are in the `OFL-*.txt` files beside the fonts. Hosted here so the calculator makes no requests to fonts.googleapis.com / fonts.gstatic.com.
